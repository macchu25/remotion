# Short-Form Retention Skill

Guidelines for keeping viewers engaged throughout 15-60 second vertical videos.

## Core Rules

1. **The 3-Second Hook**:
   - The first 3 seconds must state the core problem or surprising insight immediately ("Dừng lại! Đừng viết code thế này nữa...").

2. **Visual Resets Every 2-3 Seconds**:
   - Change visual element, camera zoom, or text focus at least once every 2-3 seconds to prevent drop-off.

3. **CapCut/Hormozi Kinetic Captions**:
   - Display captions in lower-center area (`bottom: 120px-150px`).
   - Use high-contrast font (`Be Vietnam Pro` bold) with neon word highlights matching the voiceover.

4. **Loopability**:
   - Design the final 2 seconds to transition naturally back into the first second for seamless looping.

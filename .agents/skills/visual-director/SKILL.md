# Visual Director Skill

Guidelines for visual aesthetics, color grading, and typography in modern video apps.

## Key Principles

1. **Dark Mode & Neon Accent Palettes**:
   - Backgrounds: Deep slate/midnight (`#070a12`, `#0d1322`, `#02040a`).
   - Accents: Electric Cyan (`#38bdf8`), Emerald Green (`#10b981`), Radiant Pink (`#ec4899`), Violet (`#c084fc`).

2. **Glassmorphism & Depth**:
   - Use `backdropFilter: "blur(16px-20px)"`, translucent backgrounds (`rgba(255, 255, 255, 0.04)`), and subtle glowing borders (`1px solid rgba(255, 255, 255, 0.1)`).

3. **Typography**:
   - Primary Vietnamese Font: `'Be Vietnam Pro'` (Weights 400, 600, 800, 900).
   - Code & Math Font: `'Fira Code'`.
